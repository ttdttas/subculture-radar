# 🎮 서브컬쳐 레이더

블루 아카이브 · 원신 · 젠레스 존 제로 · 붕괴: 스타레일 · 명조의
**새 떡밥 / 공식 소식 / 커뮤니티 화제글 / 많이 찾는 검색어**를 **10분마다** 자동으로 모아서
개인 웹사이트에 보여 주고, 하루 3번 디스코드·텔레그램으로 요약을 보내는 프로그램입니다.

🌐 **사이트: https://ttdttas.github.io/subculture-radar/**

- Python 3.11 이상, **추가 설치 필요 없음** (기본 라이브러리만 사용)
- GitHub Actions에서 무료로 돌아가서 **컴퓨터를 꺼도 됨**

- 영어·일본어·중국어 제목은 **자동으로 한국어 번역** (원문도 함께 표시). 게임·캐릭터 이름은 `config.toml`의 `[glossary]` 용어집대로

- 디시 말머리·아카 탭이 그림/창작/짤이면 제외, 후방(🔞) 글 제외
- 이미 본 글이 다시 잡히면 새 소식으로 치지 않고 **추천·댓글 수만 갱신**

### 🔍 검색어 색깔은 이렇게 정해요
각 출처의 자동완성은 **많이 검색되는 순서**로 나옵니다. 출처마다 위에 있을수록 점수를 주고(네이버 1.2배, 구글·유튜브 1배),
나무위키 인기 검색어(2.5배)·구글 트렌드 급상승(3배)에 뜨면 크게 더하고, **여러 곳에 동시에 뜨면 보너스**를 줍니다.
그 게임의 1등 점수 대비 비율로 색을 칠해요.

| 색 | 기준 |
|---|---|
| 🔴 빨강 — 매우 인기 | 1등의 70% 이상 |
| 🟠 주황 — 인기 | 45% 이상 |
| 🟡 노랑 — 보통 | 25% 이상 |
| ⚪ 회색 — 낮음 | 그 아래 |

정확한 검색 "횟수"를 공개하는 무료 API가 없어서 **순위를 합친 상대 점수**예요.

## 어떻게 돌아가나

- `.github/workflows/radar.yml` 이 **10분마다** `radar.py`를 실행 → 사이트 다시 배포
- 상태·누적 데이터는 **`data` 브랜치**에 저장(매번 덮어써서 기록이 쌓이지 않음)
- 디스코드/텔레그램 알림은 **07:50 · 11:50 · 18:50** 에만, 직전 알림 이후 새 소식을 묶어서 보냄
- 검색어는 요청 수를 줄이려고 **30분마다** 새로 고침
- 디시·아카·Reddit 등 한 사이트가 막히면 그 회차엔 그 사이트만 건너뜀

> GitHub의 10분 예약 실행은 서버가 붐비면 몇 분씩 늦거나 가끔 건너뛸 수 있어요.
> 1분 간격은 GitHub에서 불가능하고(최소 5분), 각 사이트에서 차단당할 위험이 커서 10분으로 했습니다.

### 알림 받기
저장소 **Settings → Secrets and variables → Actions** 에 등록:

| 이름 | 값 |
|---|---|
| `DISCORD_WEBHOOK_URL` | 디스코드 채널 설정 → 연동 → 웹후크 → URL 복사 |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | `@BotFather` 토큰 / 채팅 ID |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 선택 — <https://developers.naver.com/apps> 검색 API |
| `REDDIT_CLIENT_ID` / `REDDIT_CLIENT_SECRET` | 선택 — 이미 승인받은 Reddit 앱이 있을 때만 |

바로 시험해 보려면 **Actions → 서브컬쳐 레이더 → Run workflow** 에서 "지금 바로 알림도 보내기"를 체크하고 실행하세요.

## 내 PC에서 돌리기

```bash
python radar.py --dry-run      # 저장·전송 없이 최근 24시간 결과만 출력
python radar.py --notify-now   # 한 번 수집 + 바로 알림
python radar.py --loop         # 켜 두면 10분마다 계속 수집
```
데이터는 이 폴더의 `state/`, `site/data/` 에 생겨요. `site/` 폴더를 아무 웹서버로 열면 사이트가 보입니다
(예: `python -m http.server -d site`).

## 내 입맛대로 바꾸기 (`config.toml`)

- **게임 추가**: `[[games]]` 블록 복사 → 이름·검색어·디시 갤러리 ID·아카 채널만 바꾸기
- **알림 시각**: `notify_times` / **수집 간격**: workflow 의 `cron`
- **분류 키워드**: `[keywords]` 의 `leak` / `official` / `hot`
- **거르기**: `exclude`(제목), `exclude_flair`(말머리·탭)
- **번역 용어집**: `[glossary]`

테스트: `python -m unittest discover -s tests -v` (인터넷 없이 가짜 데이터로 전체 흐름 검사)

- 유출 정보는 **확인 안 된 정보**예요.
